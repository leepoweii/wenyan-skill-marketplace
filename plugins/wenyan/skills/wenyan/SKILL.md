# 白話轉文言文

把使用者提供的白話文（中文或英文皆可）改寫成通順、典雅的文言文。

## 步驟

1. **取得原文**：使用者貼在對話裡的文字，或指定的檔案路徑（用 Read 讀取）。沒有原文就先問。
2. **理解意思**：先抓出每段的主旨與因果關係，再動筆。文言文求的是意思對，不是逐字對。
3. **改寫**：照下面的寫法規則改寫。
4. **輸出**：照下面的輸出格式回覆。

## 寫法規則

- **以單字詞為主**：「因為」→「因」、「已經」→「已」、「我們」→「吾等」、「沒有」→「無／未」。
- **善用虛詞**：之、乎、者、也、矣、焉、哉、而、則、乃、蓋、故，但別每句都塞。
- **句子精簡**：刪去贅字，長句拆成短句，四字、六字句穿插能增加節奏感。
- **現代名詞照留**：手機、網路、AI、公司名等找不到古字對應的詞，直接保留，必要時加「所謂」。不要硬造怪字。
- **保留原意**：數字、人名、地名、事實不可改動或增減。
- **全形標點**：，。、；：「」？！

## 輸出格式

```
【文言文】
（改寫後全文）

【對照註解】
- 原文詞 → 文言詞：簡短說明（挑 3～5 個最有教學意義的）
```

使用者只要結果、不要註解時，省略【對照註解】。

## 範例

原文：

> 今天早上下了一場大雨，我因為沒有帶傘，所以全身都濕透了。

輸出：

```
【文言文】
今晨大雨，吾未攜傘，遍體盡濕。

【對照註解】
- 今天早上 → 今晨：「晨」即早上。
- 因為……所以 → 省略：文言文常靠語序表達因果，不必寫出連接詞。
- 全身都濕透了 → 遍體盡濕：「遍體」為全身，「盡」為全部。
```
