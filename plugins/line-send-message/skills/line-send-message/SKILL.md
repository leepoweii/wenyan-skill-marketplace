# LINE 傳訊息（桌面版）

用使用者電腦上的 LINE 桌面版（macOS），以本人身分傳訊息給指定聯絡人或群組。

## 前置條件
- 需要電腦操作（computer use）權限。如果沒開，告訴使用者到設定開啟後再試，不要嘗試其他方式代發。
- LINE 官方 API 只能用官方帳號／機器人發訊息，不能代替個人帳號，所以這個 skill 不走 API。

## 輸入
- **聯絡人名稱**（顯示名稱或群組名稱）
- **訊息內容**
缺任何一項就先問。

## 步驟
1. **確認內容**：確認收件人和訊息全文。傳給新聯絡人、群組，或訊息很長或敏感時，先把全文顯示給使用者確認再送。
2. **開啟 LINE**：開啟或切到 LINE 桌面版主視窗。
3. **搜尋**：在「全部」分頁上方的搜尋框（「搜尋聊天和訊息」）輸入聯絡人名稱。中文輸入法要確認選字完成，搜尋框裡顯示的是正確的字。
4. **選對象**：看搜尋結果的「聊天」區塊（不要選「訊息」區塊，那是訊息內容搜尋結果）。
   - 只有一個完全相符：點進去。
   - 有好幾個相近的名稱（例如「小明」和「小銘」，或同名的群組）：列出來請使用者選，不要自己猜。
   - 沒有任何結果：停下來回報，不要改傳給別人。
5. **核對聊天室**：開啟的聊天視窗上方顯示的名稱必須跟目標聯絡人一致。
6. **輸入並送出**：點底部「輸入訊息」框，輸入訊息內容，按 Enter 送出。多行訊息用 Shift+Enter 換行，最後才按 Enter。
7. **驗證**：截圖確認綠色訊息泡泡已經出現在聊天室最下方，並且有時間戳。
8. **回報**：「已傳給 X：『Y』（時間）」。

## 規則
- 只開目標聊天室，不讀、不轉述其他聊天室或未讀訊息的內容。
- 不重複發送。送出失敗或不確定有沒有送出時，先截圖確認，不要直接重送。
- 一次只處理使用者明確指定的收件人。
