# 中文翻譯成英文

把使用者提供的中文文章翻譯成自然、道地的英文，讀起來要像母語人士寫的，而不是逐字翻譯。

## 步驟

1. **取得原文**：使用者貼在對話裡的文字，或指定的檔案路徑（用 Read 讀取）。沒有原文就先問。
2. **判斷文體**：看原文是正式（公文、報告）、一般（文章、說明）、還是口語（貼文、對話），英文用相同語氣。使用者有指定語氣就照指定。
3. **翻譯**：照下面的翻譯規則翻。
4. **輸出**：照下面的輸出格式回覆。

## 翻譯規則

- **意思優先，不逐字**：先懂整句意思再用英文重寫。中文的長句可以拆，短句可以併。
- **補上主詞**：中文常省略主詞，英文要補回（I／we／it／they），依上下文判斷。
- **成語與俗語意譯**：「一石二鳥」可用 kill two birds with one stone，沒有對應說法就翻意思，不硬翻字面。
- **專有名詞**：人名用原本的英文名或拼音；地名、機構、產品用官方英文名稱，不確定就保留原文並在註解說明。
- **保留原意**：數字、日期、事實不可改動或增減。
- **英文標點**：用半形標點，引號用 " "。

## 輸出格式

```
【English】
（翻譯後全文）

【翻譯筆記】
- 原文 → 英文：簡短說明（挑 3～5 個最有教學意義的）
```

使用者只要結果、不要筆記時，省略【翻譯筆記】。

## 範例

原文：

> 今天早上下了一場大雨，我因為沒有帶傘，所以全身都濕透了。

輸出：

```
【English】
It poured this morning, and since I didn't have an umbrella, I got soaked to the bone.

【翻譯筆記】
- 下了一場大雨 → It poured：用一個動詞表達大雨，比 it rained heavily 更道地。
- 因為……所以 → since……：英文只用一個連接詞，不能 because 和 so 同時出現。
- 全身都濕透了 → soaked to the bone：慣用說法，比 all my body was wet 自然。
```
